Browser fallback

Review a job page locally. Nothing is sent to an AI service. Copy only the fields you approve, then paste them into your private Notion tool.

Page text — local only

Only the top frame is read. For noisy pages, select the job description before clicking the extension. Remove personal information or unrelated text below. AI uses the first 6,000 characters.

Optional local AI

Downloads an open-weight Qwen model to this browser on first use (hundreds of MB). Uses your own device's GPU and storage, not API credits. Requires WebGPU; manual review/copy works without it. Model downloads contact Hugging Face, but job text is not uploaded. AI can be wrong.

Review fields

Only confirmed, blank Notion fields will be filled. Leave uncertain fields blank. Do not treat a staffing agency as the employer unless that is what you intend to track.

In the Apps Script tool, open Browser fallback, paste the reviewed data, preview the matching Notion row, then confirm. Apply Date is chosen there; blank defaults to the confirmation date. The copied data contains your job details. Paste it only into your private tool.
